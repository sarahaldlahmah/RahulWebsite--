# RahulWebsite--
Practice exercises and test automation code written while following the "Selenium WebDriver with Java – Basics to Advanced + Frameworks" course by Rahul Shetty on Udemy.


Tech Stack
1. Java
2. Selenium WebDriver
3. TestNG
4. Eclipse IDE
5. Maven

Topics Covered:
1. Locator strategies (XPath, CSS Selectors)
2. Wait strategies (Implicit, Explicit, Fluent Wait)
3. Handling dropdowns, alerts, and frames
4. Actions class (hover, drag & drop)
5. Page Object Model (POM)
6. TestNG annotations and assertions
7. Working with lists and dynamic web elements


This project is part of my journey transitioning from manual QA to automation testing.
Currently learning and growing
